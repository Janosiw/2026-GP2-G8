# Brainalyze

Brainalyze is an AI-powered web application for brain tumor analysis using MRI scans. The system provides tumor classification, 2D/3D segmentation, diagnostic report generation, and patient management functionalities.

---

## Installation Instructions

### Prerequisites
- Python 3.10+
- Git
- Firebase Account
- Required Python packages

### Clone Repository

git clone https://github.com/Janosiw/2026-GP2-G8.git

cd 2026-GP2-G8

### Install Dependencies

pip install -r requirements.txt

### Configure Firebase

Place the Firebase service account key file inside:

shared/firebase_key.json

### Run Application

python app.py

The application will run on:

http://127.0.0.1:7860

## Additional Testing Information

### Supported MRI Formats

- JPG
- PNG
- NIfTI (.nii)
- NIfTI (.nii.gz)

### Features Available

- Radiologist Registration
- Login with 2FA
- Patient Management
- Case Management
- MRI Classification
- 2D Segmentation
- 3D Segmentation
- Diagnostic Report Generation
- Dashboard Analytics
- Similar Case Retrieval
- Report Export (PDF)
